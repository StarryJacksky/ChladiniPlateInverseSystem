# 剩余工作顺序表

[语言](./remaining_work_plan.md): [双语](./remaining_work_plan.md) | 中文 | [English](./remaining_work_plan.en.md)

本文把 Codex 现在还能继续做的任务，与需要真实材料、COMSOL 或实体测试数据后才能做的任务分开。

## A. 现在可以继续做

### 1. 前端设计打磨

目标：让软件像正式工程设计控制台，而不是临时调试页。

任务：

1. 统一 Target、Tune、Results、Run 页签的视觉层级。
2. 收紧 Results 和 Run 页的间距、文字层级和空状态。
3. 保持首屏是可用工作区，而不是营销页面。
4. 每次可见改动后，用浏览器检查桌面和窄屏布局。

### 2. 前端功能补齐

目标：让用户不用手动打开文件，也能完成绘制/导入、运行、查看和比较。

任务：

1. 增强候选之间的横向比较视图。
2. 增加更清楚的最佳候选摘要和排名解释。
3. 将报告式导出从单个候选扩展到整次运行摘要。
4. 改进导入照片和 Logo 的目标质量建议。

### 3. 自动化稳健性

目标：在让用户信任一键自动化前，让 Run 页行为足够可预测。

任务：

1. 在干净的 Windows、macOS、Linux 机器上验证 COMSOL/MATLAB 运行进程检测与安装路径发现。
2. 最终 COMSOL 模型冻结后，增加更深入的模型专属运行前检查。
3. 保持 Python-only 自检不依赖 COMSOL/MATLAB 实际启动。

最近完成：

- 已完成 COMSOL/MATLAB 自动发现、路径确认与诊断验证的前端安装向导。
- 已完成本地安全停止入口，并持久化 cancelling/cancelled 工作流状态。
- 已完成结合工作流状态、诊断和最近 COMSOL/MATLAB 日志的后端恢复建议。

### 4. 后端检查与合同

目标：在昂贵的 COMSOL/MATLAB 运行前发现配置问题。

任务：

1. 在安全的前提下增加非侵入式 COMSOL/MATLAB 版本探测。
2. 安装流程优先使用已运行进程，其次查找常见安装目录，最后才进入手动覆盖。
3. 当自动发现失败时，在安装向导中提供手动覆盖字段。
4. 当诊断发现风险时，提供更清楚的认证/license 指引。
5. 保持生成产物可恢复，清理逻辑保守。

最近完成：

- 已完成几何、厚度、材料、仿真、优化、路径和 COMSOL 端口数值的配置合同诊断。
- 已完成安装路径样例、配置路径缺失和运行进程优先级的自动发现测试。

### 5. 文档开发版

目标：即使最终截图和实验室参数还没定，也让 GitHub 当前可读。

任务：

1. 保持 README 是简洁入口页。
2. 维护 `docs/deployment_guide.md` 中的 Windows/macOS/Linux 部署指南。
3. 维护 `docs/user_manual.md` 中的软件说明书。
4. 等 UI 稳定后再补最终截图。

### 6. 无 COMSOL 烟测路径

目标：让新用户先在没有 COMSOL 的情况下验证软件。

任务：

1. 在干净环境确认 clone、安装、自检、启动流程。
2. 确认目标导入、预处理、候选生成和 UI 刷新。
3. 记录烟测后应出现的文件。

## B. 需要真实项目数据后再做

### 1. 材料校准

需要实测或可信的密度、杨氏模量、泊松比和热参数。

### 2. COMSOL 基准模型冻结

需要最终 MPH 模型、最终孔/垫片假设、最终边界命名和最终固定约束。

### 3. 实体验证

需要实体板频率、激励设置，以及拍摄或提取的实体节点线图案。

### 4. 优化调参

需要足够 COMSOL 结果来调整评分权重、随机搜索设置和遗传算法算子。

### 5. 最终发布指南

需要稳定 UI 截图、最终安装路径、实验室专属 COMSOL/MATLAB 注意事项和确认过的故障排查案例。

## C. 当前等待边界

Codex 目前还没有进入等待阶段。

下一步继续做：COMSOL/MATLAB 运行进程检测与自动发现、前端打磨、比较/报告功能、运行校验/取消行为、后端配置加固和文档细化。

只有这些完成后，项目才主要进入等待真实材料数据、最终 COMSOL 模型验收和实体验证数据的阶段。
