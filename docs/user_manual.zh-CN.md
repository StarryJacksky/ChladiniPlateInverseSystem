# 软件使用说明书

[语言](./user_manual.md): [双语](./user_manual.md) | 中文 | [English](./user_manual.en.md)

本说明书解释当前 Chladni Studio 的使用流程。

## 1. 软件做什么

Chladni Studio 帮助用户把目标视觉图案转换为阶梯厚度板候选设计。

```text
目标图案 -> 预处理 -> 厚度候选 -> COMSOL/MATLAB 仿真 -> 评分 -> 排行结果
```

## 2. 主界面

主界面左侧是绘图画布，右侧是控制页签。

顶部控制：

- `Brush`：绘制深色目标线。
- `Erase`：擦除笔迹。
- `Width`：调整画笔宽度。
- `Stroke`：把线条作为节点线目标。
- `Edge`：从填充 Logo 或照片中提取边缘。
- `Filled`：把填充区域本身作为目标。
- `Import`：导入 PNG/JPEG/WebP 图片。
- `Save`：保存并预处理目标。

## 3. Target 页

这个页签用于准备用户给定图案。

推荐目标图：

- 高对比度。
- 第一轮搜索不要过于复杂。
- 不要太细小，也不要大面积填满。
- 第一轮尽量避免很多孤立小碎片。

`Target Quality` 会显示：

- 预处理预览。
- 前景面积比例。
- 连通部分数量。
- 第一轮适配建议。
- 细节、复杂度和面积平衡警告。
- 针对导入照片、Logo 和复杂手绘目标的简短质量建议。

如果建议是 `Late-stage target`，可以等优化流程稳定后再用，或先简化图案。

## 4. Tune 页

这个页签用于编辑材料和评分参数。

材料参数：

- 密度。
- 杨氏模量。
- 泊松比。
- 导热系数。
- 热容。
- 热膨胀系数。

评分参数：

- 粗糙度权重。
- 质量权重。
- 频率权重。
- 频率范围。

修改材料或评分参数后，请点击 `Apply`。

## 5. Run 页

这个页签用于运行自动化流程。

运行预设：

- `Smoke`：1 个候选、3 个模态，用于快速检查。
- `Review`：3 个候选、10 个模态，用于短对比。
- `Full`：12 个候选、20 个模态，用于较完整本地搜索。

`Run COMSOL`：

- 开启：运行 COMSOL/MATLAB 桥接。
- 关闭：只运行 Python 侧流程，不跑 COMSOL 仿真。

运行控制：

- `Run`：通过运行前检查后，启动本地排队工作流。
- `Stop`：请求安全取消；当前外部 COMSOL/MATLAB 命令不会被强杀，工作流会在下一个安全检查点停止。

运行前检查：

- 候选数量必须是 1 到 100。
- 模态数量必须是 1 到 60。
- 目标图应至少保存一次，以生成预处理指标。
- 如果开启 `Run COMSOL`，诊断状态应为 ready。

诊断：

- `Refresh`：检查配置合同、路径、模型、runner、超时设置和 mphserver 可达性。
- `Self-test`：运行更安全的 Python-only 部署检查。

时间线与日志：

- Timeline 显示排队、目标预处理、候选生成、仿真、评分、正在取消、已取消、完成和错误阶段。
- Logs 显示最近的 COMSOL/MATLAB 输出尾部。
- 失败时，Recovery hints 会结合工作流状态、诊断和最近日志，提示下一步检查。

产物：

- 显示生成文件大小。
- 预览可清理文件。
- 只清理保留策略允许的可再生成或临时文件。

## 6. Results 页

这个页签用于查看已评分候选。

你可以：

- 按编号搜索候选。
- 按排名、分数、IoU、Dice 或频率排序。
- 按最小 IoU 过滤。
- 放大查看目标、仿真、叠加图片。
- 在已评分模态之间切换。
- 在总览区横向比较当前可见的前几个候选。
- 从总览区打开整次运行报告。
- 打开可读的候选报告。
- 下载候选结果包。

最佳候选不一定是 IoU 最高的候选，因为最终分数可能包含粗糙度、质量和频率惩罚。

## 7. 新手典型流程

1. 启动 Chladni Studio。
2. 绘制或导入简单目标。
3. 填充 Logo/照片选 `Edge`，手绘线条选 `Stroke`。
4. 点击 `Save`。
5. 检查 `Target Quality`。
6. 打开 `Tune`，确认材料和评分设置。
7. 打开 `Run`，选择 `Smoke`，点击 `Run`。
8. 如果烟测成功，再尝试 `Review` 或 `Full`。
9. 打开 `Results`，查看最佳候选。

## 8. 如何理解结果

关键指标：

- IoU：仿真节点区域与目标区域的重叠程度。
- Dice：另一种相似度指标，常用于视觉比较。
- Frequency：COMSOL 导出的模态频率。
- Final score：相似度扣除惩罚项后的综合分数。

快速判断时先看叠加图，再比较指标。
