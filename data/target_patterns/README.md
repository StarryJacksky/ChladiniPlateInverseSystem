# Target Pattern Folder

请把第一张目标图命名为：  
Please name the first target image:

```text
target.png
```

建议第一张图使用简单的黑白线条，例如十字、斜线、C 形或简单弧线。  
For the first image, use a simple black-and-white line drawing, such as a cross, diagonal line, C shape, or simple arc.

Logo 或字母图案可以作为后期测试目标，但第一版 `6 x 6` 厚度矩阵可能无法精确复现细节。  
Logo or letter patterns can be used as later-stage targets, but the first-version `6 x 6` thickness matrix may not reproduce fine details accurately.
